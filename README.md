# 价值判断 Skill

> 判断一个产品需求值不值得做——把拍脑袋的直觉，变成可计算、可沟通、可复查的理性决策。

## 这是什么

一个可落地的产品经理 Skill。用「用户价值 = 新体验 - 旧体验 - 替换成本」公式和「价值三问」，在动手画原型之前先判断需求值不值得做。

## 核心公式

> 用户价值 = 新体验 - 旧体验 - 替换成本

一个需求有没有价值，不看功能多不多、技术牛不牛，只看三个变量的账算下来是正还是负。

## 适用场景

- 需求池里堆了一堆需求，不知道先做哪个
- 老板拍了一个需求，你心里没底
- 研发问「这个需求到底解决了什么问题」，你答不上来
- 想拒绝一个需求，但拿不出理由

## 怎么用

1. 打开 `SKILL.md`，里面有完整的操作框架、步骤、模板和检查清单
2. 把它当「操作手册」：接到对应工作时，照着步骤一步步走
3. 可以直接复制里面的「输出模板」，填入你的实际内容
